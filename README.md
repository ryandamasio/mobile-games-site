# Mobile Games ABC — site conceito

Landing page para a Mobile Games (@mobilegamesabc), loja de games do ABC Paulista.

- Hero 3D com moedas colecionáveis e o mascote, que acompanha o scroll
- Estante de categorias com abas próprias (`#/loja/consoles`, `#/loja/jogos`, ...)
- Seção PC Gamer com placa-mãe isométrica em 3D
- Mural de clientes, mapa e links

Arquivo único: `index.html` (Three.js via CDN). Para trocar o WhatsApp, edite `CONFIG.whatsapp` no começo do script.
